# GreenMart Teaser

Animated soft-launch page and waitlist for GreenMart. Grass grows as you scroll, the wordmark rises out of the field, and visitors join as a farmer, seller or buyer.

```bash
npm install
npm run dev
```

Signups are stored in `.data/waitlist.json` during development. See `CLAUDE.md` for the next tasks and `docs/PRD.md` for the full spec.
